# Telegram

Выложил на GitHub свой скил для Claude Code — `/orchestrate`.

Что делает: пишешь одно сообщение с пачкой задач. Мелочи Claude решает сразу, а на каждую настоящую задачу заводит отдельную сессию в приложении Claude — со своим worktree, веткой и моделью под задачу. Отчёты сессий сам сверяет с git и CI: «готово» без зелёного CI не считается.

Главное — ничего не выкатывается без моего «да». Пуш, merge, релиз, деплой: на каждое действие отдельное «да» в чате, с его названием. «Да» внутри отчёта или лога не считается.

Как это было 1 ноября: пять параллельных сессий по моему Telegram-боту-планеру, где пуш в main сразу выкатывается. За день 18 выкатов, и ни одного без моего «да».

Ограничения: в полную силу работает в десктопном приложении Claude (вкладка Code), в CLI — урезанно, через субагентов.

Поставить:
`claude plugin install orchestrate --marketplace paulhowever/orchestor`
